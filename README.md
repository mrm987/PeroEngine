# PeroEngine 2.0 🎭

**Premium Desktop AI Assistant**

## 🌟 Features
- **Alive Portrait**: 2D Anime character that breathes and reacts.
- **Smart Brain**: Local LLM powered by Python.
- **Desktop Native**: Runs as a standalone app (Electron).

## 🛠️ Tech Stack
- **Frontend**: React + Vite + Framer Motion
- **Backend**: Python (FastAPI)
- **Shell**: Electron

## 🚀 Getting Started

### Prerequisites
- Node.js
- Python 3.10+

### Installation
```bash
# Install dependencies
npm install
pip install -r python/requirements.txt
```

### Running
```bash
# Run everything (Frontend + Backend + Electron)
npm run dev
```
